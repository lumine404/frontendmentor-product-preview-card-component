## 🎯 What I Learned

This project helped me improve my understanding of:

- Creating responsive layouts with CSS Grid.
- Using Flexbox to center elements both horizontally and vertically.
- Using `width: 100%` together with `max-width` to create responsive cards.
- Creating mobile layouts with CSS media queries.
- Understanding how the CSS cascade affects which rules are applied.
- Using different layouts for desktop and mobile screen sizes.
- Using `object-fit: cover` to control how images fit inside their containers.
- Using `gap` to create consistent spacing between Flexbox elements.
- Importing and applying custom fonts from Google Fonts.
- Using CSS custom properties for colors and maintaining consistent styling.
- Managing spacing with padding and understanding the difference between padding and margin.

## 💡 Challenges

Some challenges I encountered while building this project included:

- Getting the card properly centered on the page without making it unnecessarily large.
- Finding the right combination of `width` and `max-width` to keep the card responsive.
- Making the product image fill the card correctly without leaving unwanted spacing.
- Creating a separate mobile layout where the image and content stack vertically.
- Understanding why my mobile media query was not initially overriding the desktop Grid layout.
- Learning how the CSS cascade and source order affect which styles take priority.
- Getting the spacing between the cart icon and text to look right.
